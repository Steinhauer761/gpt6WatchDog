Username / People OSINT

Search public information connected to a username, alias, name, email or domain. Results are leads, not proof that two accounts belong to the same person.

What this can find

Public profiles, reused usernames, indexed documents, social mentions, public code references, domain context and Tor-index pivots.

What it does not do

No private account access, login bypass, credential theft, private-address databases or hidden personal records.

Footprint Audit

Build broader public-source pivots for an identifier you are researching.

Incident Console

Paste suspicious material and extract indicators locally before using external reputation services.
Local analysis stays in the browser. The heuristic score is only a triage aid.
