Metadata / Provenance

ExifTool, MediaInfo and C2PA checks for timestamps, software tags, device metadata, edit history clues and signed provenance when present.

Video / Frame Analysis

FFmpeg/FFprobe and OpenCV sampling for codec changes, discontinuities, duplicate frames, unexpected frame-rate shifts and visual edit boundaries.

Audio Analysis

Inspect codec, sample rate, channel layout, abrupt spectral changes and possible splice boundaries. Audio cues are supporting signals, not proof.

Image Analysis

Dimensions, compression, metadata, edge/noise inconsistencies, duplicated regions and edit artifacts. Re-saving can erase or create artifacts.

Text / Document Analysis

Look for contradictory dates, changing names, formatting shifts, impossible timelines, inconsistent terminology and metadata conflicts.

AI / Deepfake Signals

Use provenance plus multiple model/forensic signals. No single detector should be treated as a definitive deepfake verdict.

How WatchDog Should Report Results

Observed fact: directly measurable information such as file hash, resolution, codec, duration, metadata or a visible timestamp.
Forensic signal: something unusual that deserves review, such as a discontinuity or conflicting metadata.
Assessment: a cautious interpretation combining multiple signals and context.
A missing C2PA credential does not mean media is fake. Metadata can be removed. Compression and social-media re-encoding can create artifacts. Deepfake detectors can produce false positives and false negatives.
