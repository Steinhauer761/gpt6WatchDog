WatchDog Assistant

Ask questions or have the assistant run passive WatchDog tools such as public-source search, Tor-index search, IP intelligence, site crawl and text triage.
WatchDog: I can answer questions and use passive tools. I won’t treat a username match as proof, and an IP location is only an approximate network estimate—not a person’s exact location.
AI requires a server-side OpenAI API key. The key is never placed in this page.
Active penetration testing stays in the separately authorized dashboard workflow. The assistant does not bypass accounts, retrieve passwords, map private home addresses, or track people in real time.
