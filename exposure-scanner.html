2. Quick Public Pivots

These links open public search sources. Treat same-name and same-username hits as leads until corroborated.

3. Web Crawl / Site Intelligence

Crawl a public website through the Linux worker. The crawl is limited to the same hostname, respects robots.txt, blocks local/private network targets, does not follow redirects, and caps depth/pages to avoid crawler traps.

4. What the Linux Worker Will Scan

Public web

Search-engine results, indexed pages, public documents, forums, news, public social profiles, public code and cached references.

Username footprint

Sherlock-style username discovery plus spelling/handle variants and cross-platform correlation.

Email / phone exposure

Public occurrences, scam reports, breach/exposure presence metadata where lawful, and known-public references. No password retrieval.

Domain infrastructure

DNS, RDAP/WHOIS, certificates, ASN, passive infrastructure links and public attack-surface context.

Tor / dark web

Tor search indexes and reachable public onion pages through an isolated worker, extracting mentions and indicators without interacting with illegal marketplaces or private accounts.

Correlation

Rank matches by exactness, contextual overlap, date consistency, reused usernames/domains and independent-source corroboration.

5. Result Classes

Exact

Identifier matches exactly and is supported by contextual evidence.

Likely

Strong overlap across multiple independent public signals, but identity is not proven.

Weak

Partial or common-name match requiring manual verification.

Unverified lead

Interesting mention with insufficient evidence to associate it with the subject.

WatchDog should never label a person as a criminal, scammer or account owner solely from a username/name match. Private addresses, credentials, private messages and login-protected data are outside this scanner.
