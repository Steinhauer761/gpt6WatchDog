Global Map + Street View

Working public data

Find places, view map links and inspect approximate network or satellite positions.

What can it do?
  • Search an address or place and copy its mapped coordinates.
  • Open Google Street View or Maps where coverage exists.
  • Look up an IP address's approximate network location and organization; it cannot locate a person precisely.
  • Find satellites by name from published orbit data. This is an estimate, not a live camera.

Example

Check a meeting location, then open the Street View link to recognize the entrance.

Limits

Street View coverage varies. Maps and orbit services need a connection. An IP result is not a home address.

WatchDog Console

Working; probes need authorization

Research and triage in one place, with bounded security checks on systems you may assess.

What can it do?
  • Save the target and scope locally before running an authorized web or network probe.
  • Check a site's security headers or common open ports when you own it or have permission.
  • Find public web leads, extract URLs and IPs from evidence text, and look up public IP network details.
  • Show worker capabilities. NFC and Bluetooth features depend on browser and phone hardware.

Example

On your own site, save the scope, inspect headers and put relevant URLs into an incident note.

Limits

It is not a general vulnerability audit; probe permission is required. NFC/Bluetooth may be unsupported.

Exposure Scanner

Public search works; Tor varies

Search public sources for an identifier and follow links you can verify yourself.

What can it do?
  • Search public web, GitHub, Hacker News and certificate records for names, usernames, email addresses or domains.
  • Show source links and errors if a source does not respond.
  • Crawl a small public site while respecting robots rules.

Example

Search your own username and review each result before deciding whether it refers to you.

Limits

Ahmia's Tor index currently rejects worker requests. Direct onion retrieval needs a Tor proxy that is not configured. Private or deleted posts are not exposed.

Open exposure scanner

Vehicle Intelligence

VIN works; OCR needs download

Decode public vehicle specifications and save a plate observation locally.

What can it do?
  • Check a 17-character VIN locally and fetch make, model, year and available specifications from NHTSA.
  • Choose a plate photo, try local OCR, correct the suggested text and download a timestamped JSON observation with the original image hash.

Example

Compare a used vehicle listing's claimed model with the free VIN decoder, or preserve what you saw in a photo.

Limits

OCR needs an initial language data download and may misread characters. No registration, owner lookup, recall check or automatic plate matching.

Scam / Fake Account

Working local case tool

Organize clues from suspicious messages and files.

What can it do?
  • Extract visible indicators from pasted messages, such as links, emails or numbers.
  • Calculate a file's SHA-256 hash so you can recognize the same evidence later.
  • Open public search links and download a case JSON with your notes.

Example

Keep a copy of a suspicious message and its screenshot hash before reporting an account.

Limits

It does not identify the sender or decide if a message is fraudulent.

Media Forensics

Working local triage

Measure a file and list text claims worth checking.

What can it do?
  • Hash selected images, video, audio or documents and record file size and local modified date.
  • Read image dimensions, video/audio duration where supported, and common JPEG camera, software and date tags.
  • List dates, numbers and repeated sentences from pasted text; download a local JSON report.

Example

Hash a received photo and note any embedded camera time before comparing it to a claim.

Limits

Metadata can be removed or changed. No full EXIF, C2PA, splice analysis, external fact check or deepfake verdict.

Open media triage

Impersonation Defense

Working local case tool

Compare evidence and prepare a platform report.

What can it do?
  • Hash submitted evidence and compare two images by approximate visual hash.
  • Build public search links for profile claims and export a case packet.

Example

Compare an account photo with your original and save links and dates for a platform complaint.

Limits

Similar images do not establish identity. The tool does not access private accounts or file a report for you.

Privacy / OPSEC

Browser-dependent checks

See what your browser reveals and clean a shareable copy.

What can it do?
  • Ask a third-party IP service for your visible public IP.
  • Inspect browser properties and available WebRTC candidate types.
  • Remove common tracking parameters from a link; download a canvas-rendered JPEG without the original file metadata.
  • Review a practical privacy checklist.

Example

Clean a campaign link before sharing it or prepare a metadata-stripped copy of an image.

Limits

Browser restrictions affect tests; stripping metadata changes the image and cannot erase copies already shared.

WatchDog Assistant

Off by your choice

AI chat and its OpenAI API use are paused.

What would it do if enabled?

It could answer questions and coordinate passive public research. It would require a new private API key and could create usage charges.

Today

Use the independent tools above. No AI calls are needed for them, and no new AI key is being added.

Active security testing is restricted to systems you own or are explicitly authorized to assess. Public search results and approximate map data are leads to verify, not proof about a person's identity or whereabouts.
